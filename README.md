# Implementation of Palindrome Checker Using Stack and Queue

## Project Description

The Palindrome Checker Using Stack and Queue is a mini project developed using Python to demonstrate the practical application of fundamental data structures. A palindrome is a word, number, or sequence of characters that reads the same forward and backward, such as MADAM, LEVEL, and RADAR.

The main objective of this project is to determine whether the given input is a palindrome by using Stack and Queue data structures. A stack follows the Last In, First Out (LIFO) principle, whereas a queue follows the First In, First Out (FIFO) principle. These data structures help process characters in different orders and compare them to identify palindromes.

## Objectives

- To understand the basic concepts of Stack and Queue.
- To implement Stack and Queue operations using Python.
- To check whether a given word or text is a palindrome.
- To understand the LIFO and FIFO principles through practical implementation.
- To improve logical thinking and problem-solving skills.

## Working of the Project

1. The program accepts a word or text as input from the user.
2. Each character is inserted into the Stack and Queue.
3. Characters are removed from both data structures according to their respective principles.
4. The removed characters are compared one by one.
5. If all corresponding characters match, the input is identified as a palindrome; otherwise, it is identified as not a palindrome.
6. The final result is displayed to the user.

## Technologies Used

## Conclusion

This project demonstrates how Stack and Queue data structures can be used together to implement a palindrome checker. It provides practical knowledge of LIFO and FIFO principles and helps students understand the importance of data structures in solving programming problems.
